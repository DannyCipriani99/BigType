# المحرر الكبير (BigType)

تطبيق أندرويد يستخدم **خدمة إمكانية الوصول**: عند الضغط على أي حقل نص في أي تطبيق تظهر نافذة كتابة كبيرة،
وعند الضغط على زر «نقل النص إلى الحقل» يُكتب النص مباشرة في الحقل الأصلي.

## التشغيل
1. افتح مجلد المشروع في Android Studio (إصدار Koala أو أحدث) واترك Gradle يكمل المزامنة.
2. شغّل التطبيق على جهاز حقيقي (أندرويد 7.0 / API 24 أو أحدث).
3. من الشاشة الرئيسية اضغط «فتح إعدادات إمكانية الوصول» وفعّل «المحرر الكبير».
4. أندرويد 13+ (عند تثبيت APK يدوياً): معلومات التطبيق ← ⋮ ← «السماح بالإعدادات المقيّدة»، ثم فعّل الخدمة.

## كيف يعمل
- `BigTextAccessibilityService`: يلتقط حدث الضغط على حقل قابل للتعديل، ويحفظ مرجعاً للحقل، ويفتح المحرر مع النص الحالي.
- `EditorActivity`: واجهة كبيرة مع عدّاد أحرف وزر نقل في الأسفل. الرجوع بعد تعديل يسأل قبل التجاهل.
- عند النقل: تعود الخدمة للحقل الأصلي وتستخدم `ACTION_SET_TEXT`، وإن فشل ذلك تنسخ النص وتحاول اللصق.

## ملاحظات
- حقول كلمات المرور يتم تجاهلها دائماً.
- حقول الأرقام والهاتف تُتجاهل افتراضياً (يمكن إيقاف ذلك من الإعدادات).
- بعض التطبيقات (مثل بعض الألعاب أو الحقول المخصصة) قد لا تكشف حقولها لإمكانية الوصول.
- عند النشر على Google Play يلزم عرض إفصاح واضح للمستخدم عن استخدام واجهة إمكانية الوصول وفق سياسات المتجر.
