# المحرر الكبير (BigType)

عند التركيز على أي حقل نص في أي تطبيق يظهر **زر عائم صغير** بجانبه. الضغط عليه يفتح **لوحة كتابة عائمة**،
وزر «نقل النص إلى الحقل» يكتب النص في الحقل الأصلي.

## المزايا
- بحث واستبدال مع Regex، وحالة الأحرف، وكلمة كاملة، ومجموعات `$1`، و`\n` للسطر الجديد.
- تراجع وإعادة، وعدّاد أحرف وكلمات وأسطر.
- مسودات تُحفظ تلقائياً عند الإغلاق، وتُحفظ النسخة الأصلية عند النقل للاسترجاع.
- أدوات نص: إزالة المسافات والأسطر الفارغة والمكررة، ترتيب وعكس ودمج وترقيم الأسطر،
  أحرف كبيرة/صغيرة، إزالة التشكيل، توحيد الألف والياء، تحويل الأرقام (0123 ⇄ ٠١٢٣).
- «نقل + Enter» لحقول البحث (أندرويد 11+).
- اتجاه النص (تلقائي/يمين/يسار) وتكبير الخط.
- استثناء تطبيقات معيّنة، وتجاهل كلمات المرور دائماً، وتجاهل حقول الأرقام اختيارياً.

## التشغيل
فعّل الخدمة من إعدادات إمكانية الوصول. على أندرويد 13+ عند التثبيت اليدوي:
معلومات التطبيق ← ⋮ ← «السماح بالإعدادات المقيّدة».
البناء يتم تلقائياً على GitHub Actions وينشر APK في صفحة Releases.
